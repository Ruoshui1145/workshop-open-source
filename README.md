# 制造工坊 · 开源源码

用于保存可公开项目的源码及选定历史版本。每个版本一并保留许可证、版权声明和必要的构建说明。

当前状态：仓库已初始化，尚未导入具体项目源码。

## 源码组织

源码按 `sources/<项目名>/<版本>/` 存放。每个版本至少包含：

- 项目源码及构建所需的配置、依赖清单和脚本。
- 该版本原有的 `LICENSE` / `COPYING`、版权声明和第三方通知。
- `README.md`：原始来源、版本或源提交、修改记录、构建环境和操作步骤。

## 收录规则

- 只收录有权公开、版本明确的源码；遵守每个项目所选版本的原始许可证。
- 提供已分发软件的对应源码时，应匹配实际分发版本及其修改，并保留必要的构建材料；旧版不能代替其他版本的对应源码。
- 不存放安装包、可执行文件、构建产物、依赖目录、运行时、密钥、账号配置、个人素材或用户数据。

本仓库不对未来收录项目统一指定许可证。具体使用权限以各项目、各版本内保留的许可文件为准。
